## [0.1.0] - 2026-11-12

### Added

- Temporarily switch to direct input while Minecraft Java Edition captures the mouse, and restore the previous input state when the mouse is released or the game loses focus.
- Block configurable shortcuts while Minecraft is in the foreground. By default, block the Windows emoji picker shortcut.
- Recognize SDL3, GLFW, and LWJGL 2 game windows and support Microsoft Pinyin, Microsoft Japanese IME, and Windows per-window keyboard layouts.
- Show the app version in the notification area’s About dialog and in Windows executable properties.
- Publish portable Windows downloads for x64 and ARM64 with an example configuration.
